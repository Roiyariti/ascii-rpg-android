# Wrapper Gradle

Wrapper oficial de Gradle 8.11.1, descargado de `gradle/gradle` (etiqueta `v8.11.1`).
El JAR coincide con el SHA-256 oficial:
`2db75c40782f5e8ba1fc278a5574bab070adccb2d21ca5a6e5ed840888448046`.
La distribución se valida mediante `distributionSha256Sum`.

Estos archivos pertenecen a Gradle y conservan Apache-2.0; consultar
[la licencia de Gradle](https://github.com/gradle/gradle/blob/v8.11.1/LICENSE).
Esto no establece la licencia del proyecto ASCII RPG, que está pendiente de elección.
